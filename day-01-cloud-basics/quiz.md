# Day 01 Quiz

Answers at the bottom. Try without looking first.

**1.** Which model gives you a virtual machine but leaves the OS and software to you?
- A) SaaS  B) PaaS  C) IaaS  D) FaaS

**2.** An isolated data center within a region is called:
- A) Edge location  B) Availability zone  C) Cluster  D) Namespace

**3.** Under shared responsibility, who is responsible for configuring MQ channel TLS?
- A) Cloud provider  B) The customer  C) Both equally  D) Nobody

**4.** Hybrid cloud means:
- A) Two public clouds only
- B) A private environment connected to a public cloud
- C) Any cloud with containers
- D) A cloud with no regions

**5.** Why spread three MQ Native HA replicas across availability zones?
- A) It lowers licence cost
- B) It survives the loss of a single zone
- C) It speeds up every message
- D) It removes the need for backups

**6.** True or false: moving to the cloud removes your responsibility for data security.

**7.** Which describes "elasticity"?
- A) Fixed capacity for a year
- B) Resources scale up and down with demand
- C) Data stored in two places
- D) Encryption at rest

**8.** In one sentence, why do we study cloud basics before the MQ Operator?

---

## Answers

1. C
2. B
3. B
4. B
5. B
6. False
7. B
8. The MQ Operator runs on OpenShift and Kubernetes, which run on cloud infrastructure, so troubleshooting needs an understanding of every layer.
